# llm - LLVM Make

A build system for C, C++ and assembly, powered by LLVM. Declare projects in
`.llm` files, discover sources automatically and build with source-package
dependencies and C++23 modules.

Supports Windows and Linux on x64 and ARM64, and macOS on ARM64.

- [Get started](https://github.com/llm-build-system/llm#installation-and-platforms)
- [Download llm 1.0.0](https://github.com/llm-build-system/llm/releases/tag/v1.0.0)
- [Project and command reference](https://github.com/llm-build-system/llm#contents)

## Projects

- [llm](https://github.com/llm-build-system/llm) - the build tool and its documentation.
- [llm-registry](https://github.com/llm-build-system/llm-registry) - the source package index.

Package repositories maintain llm build integration for their original upstream
projects. Their authors, licenses and copyright notices remain credited in each
repository. Registry inclusion does not constitute a security review or a
guarantee that a package is safe.

LLVM Make is an independent project.
