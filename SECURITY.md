# Security reports

Report vulnerabilities privately through GitHub:

- [llm, its installer and build tools](https://github.com/llm-build-system/llm/security/advisories/new).
- [The registry index and llm package ports](https://github.com/llm-build-system/llm-registry/security/advisories/new).

A GitHub account is required. Reports and their discussions are private and are
not published automatically. Do not post security-sensitive details in public
issues or discussions.

Include the affected project or package, its version, the target platform and
the minimum steps needed to reproduce the issue. Do not send credentials,
private keys or unrelated personal data.

For vulnerabilities in an upstream library, follow the upstream project's
security reporting process as well. Each package repository links to its
original project.

For general contact and project updates, use [@3754Rx on X](https://x.com/3754Rx).
